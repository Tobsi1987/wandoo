# osm_pipeline

Bereitet OpenStreetMap-Extrakte (zum Beispiel von Geofabrik) zu kompakten
Regionspaketen für das Gerät auf: Straßenabschnitte mit den Tags der Fläche,
in der sie liegen (`areaTags`, siehe `geo_engine`'s `RoadSegment`).

Noch nicht gebaut. Offen: Paketformat, Kachelgröße, Auslieferung als
statische Dateien. Lizenz ODbL: In der App muss "© OpenStreetMap-Mitwirkende"
sichtbar sein.
