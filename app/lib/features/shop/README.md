# shop

**Zweck:** Laden als Entwurf: Wegschick-Pause beenden und Straßen neu
entdecken. Bezahlen ist nur gespielt (Probekauf), echte Käufe kommen später
über App Store und Play Store.

**Bekommt:** `ShopRepository` und die Angebote (`shopOffersProvider`) aus
dem Bootstrap; die Angebote baut `flows/shop`, weil sie in Wesen und
Entdeckung eingreifen.

**Liefert:** `ShopScreen` (`/laden`), `FreeRediscover` (alle 7 Tage gratis).
