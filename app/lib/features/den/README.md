# den

**Zweck:** Die Höhle. Ab Level 25 (Stufe 3) kann das Wesen dort
Winterschlaf halten, und man bekommt ein zweites Ei. Es ist immer nur ein
Wesen aktiv; das andere braucht weder Gänge noch Futter (sein Bauch wird im
Schlaf nicht leerer). Getauscht wird mit einem Tipp, jederzeit.

**Bekommt:** das Wesen und den Schlafplatz (`DenRepository`) aus
`creature`, den Hungerbalken aus `hunger`, das Level aus `levels`.

**Liefert:** `DenButton` für die Wesenskarte, `DenScreen`,
`denUnlockedProvider` und `SwapCreatures`.
