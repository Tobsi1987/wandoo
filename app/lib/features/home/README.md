# home

**Zweck:** Startbildschirm: zeigt das Wesen in seiner Welt und startet oder
beendet einen Gang.

**Bekommt:** das Wesen aus `creature`, `WalkPanel` aus `tracking`,
`WalkSummaryCard` aus `walk_summary` und die Knöpfe der anderen Module
für die obere Leiste (`HomeTopBar`).

**Liefert:** `HomeScreen` für den Router.
