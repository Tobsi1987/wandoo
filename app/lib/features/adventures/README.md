# adventures

**Zweck:** Wöchentliche Abenteuer mit Belohnungen. Jede Woche (ab Montag)
gibt es drei Aufgaben, z. B. "Entdecke 8 neue Waldwege". Jede bringt
Fundstücke, alle drei zusammen ein Glücks-Ei.

**Bekommt:** die neuen Abschnitte je Umgebung nach jedem Gang (über
`flows/process_walk/extras/adventure_extra.dart`).

**Liefert:** `AdvanceAdventure`, `weeklyAdventureProvider`, `AdventureScreen`
und Zeilen für die Zusammenfassung. Fundstücke und Glücks-Ei vergibt der
Flow, nicht dieses Feature.
