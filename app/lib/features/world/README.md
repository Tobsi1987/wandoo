# world

**Zweck:** Lebendige Welt. Nachts schläft das Wesen und Glühwürmchen
leuchten, das Wetter (Open-Meteo, grober Ort) zeigt Regen, Schnee, Nebel
oder Sonne, und Eier tragen ein Muster je nach Jahreszeit oder Fest
(Ostern, Halloween, Weihnachten).

**Bekommt:** Uhrzeit, groben Standort (`core/location`), eine
`WeatherSource` aus dem Bootstrap.

**Liefert:** `worldStateProvider`, `WeatherLayer`, `worldLine`.
