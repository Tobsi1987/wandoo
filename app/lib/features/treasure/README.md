# treasure

**Zweck:** Fundstücke auf neuen Wegen sammeln und daraus Deko fürs Wesen basteln.

**Bekommt:** neue Abschnitte je Umgebung (über `flows/process_walk`), das Wesen
(`creature`) zum Anziehen.

**Liefert:** `DropFinds`, die Schatzkiste (`TreasureChest`), den Screen
`/schatzkiste` und die Zeile "Gefunden: …" für die Zusammenfassung.
